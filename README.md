# globia.shop

Website des Supermarkts Globia (Mönchengladbach). Live über GitHub Pages aus dem Branch `(root)`.

Die Startseite gibt es in sechs Sprachen (`index.html` = Deutsch, `en`, `fr`, `es`, `ur`, `hi`).
Texte ändern: in `_build/build.py` anpassen, dann `python3 _build/build.py` ausführen und die erzeugten `.html`-Dateien committen.
Impressum und Datenschutz (`impressum.html`, `datenschutz.html`) sind nur auf Deutsch und werden direkt bearbeitet.
